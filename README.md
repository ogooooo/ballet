# 🩰 유빈님의 발레 코디북

보유한 발레복(레오타드 4벌 · 상의/워머 4벌 · 하의 4벌 · 앵클워머 2종)으로 코디를 조합하고,
오늘의 추천 코디를 뽑고, 마음에 드는 코디와 착용 날짜를 기록하는 모바일 웹앱입니다.

https://ogooooo.github.io/ballet/

## 화면

- **코디** — 레오타드 · 상의/워머 · 하의 · 앵클워머를 탭으로 골라 조합. 고른 아이템의 컬러와
  실루엣이 SVG 일러스트로 바로 보이고, 궁합 점수와 짧은 코디 코멘트가 함께 나옵니다.
  `오늘의 추천 코디 뽑기`는 톤온톤 · 포인트 컬러 궁합 기준으로 상위 조합 중에서 골라 줍니다.
- **룩북** — 잘 어울리는 조합 6종을 카드로 모아 두었고, 카드를 누르면 조합기로 불러옵니다.
- **옷장** — 보유 아이템 전체 목록. 새 발레복(종류·실루엣·색상)을 추가하거나 지울 수 있습니다.
- **기록** — 저장한 코디(즐겨찾기)와 착용 날짜 기록. 이번 달 착용 횟수와 가장 많이 입은
  레오타드도 함께 보여 줍니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 (뉴트럴 · 로즈 · 크림 팔레트, 모바일 퍼스트) |
| `app.js` | 조합기 · 궁합 점수 · 추천 · SVG 일러스트 · localStorage 기록 |
| `data.json` | 보유 아이템 14개와 룩북 프리셋 6종 |
| `manifest.json` · `apple-touch-icon.png` · `icon-192.png` · `icon-512.png` | 홈 화면에 추가할 때 쓰는 앱 아이콘과 설정 |

## 아이폰에서 앱처럼 쓰기

사파리에서 <https://ogooooo.github.io/ballet/> 를 연 뒤 **공유 → 홈 화면에 추가**를 누르면
발레 코디북 아이콘이 생기고, 주소창 없이 앱처럼 열립니다.

## 데이터 수정

`data.json`의 `items`, `presets`를 고치면 앱에 바로 반영됩니다. 사용자가 앱에서 직접 추가한
아이템과 즐겨찾기 · 착용 기록은 브라우저 `localStorage`(`ballet.v1.*`)에 저장되므로 기기마다
따로 남습니다.

## 배포

GitHub Pages로 배포되어 있습니다: <https://ogooooo.github.io/ballet/>

- Pages 배포 소스는 **`gh-pages` 브랜치**입니다. (`main` 브랜치는 작업용)
- 수정한 뒤에는 두 브랜치를 함께 올려 주세요.

```bash
cd ballet
git push origin main
git push origin main:gh-pages
```

## 로컬에서 열기

```bash
cd ballet
python3 -m http.server 8080
# http://localhost:8080
```

`data.json`을 `fetch`로 읽기 때문에 `index.html`을 파일로 직접 열면 데이터가 보이지 않습니다.
